# 移动浏览器一期需求基线

## 目标与范围

在不拆分站点、不增加生产依赖、不改变现有 API 契约的前提下，为公开门户和读者流程提供可完整操作的移动浏览器体验。

本期包含：

- 首页、文章阅读、商城、分享赚钱、常用工具、站长福利、指南与关于页面；
- 固定五入口底部导航：`首页 / 阅读 / 商城 / 分享 / 我的`；
- 沉浸式文章阅读，以及文章列表、目录、评论、分享四项上下文操作；
- “我的”账户中心：登录/注册入口、订单概览、已购文章和常用服务；
- 复用现有 Cloudflare Turnstile 登录/注册和 Go 读者账号/文章订单接口；
- 兼容桌面与平板现有导航、布局和无刷新路由。

明确不做：移动端管理员后台、独立 `m.` 站点、原生 App、新支付通道、数据库或公共 API 变更。

## 关键规则

- 断点：手机 `<= 767px`，平板继续使用现有折叠菜单。
- 所有核心触控目标至少 `44 × 44px`。
- 固定导航和阅读器操作栏适配 `safe-area-inset-bottom`；全屏阅读使用动态视口高度。
- 工具、福利、指南、关于属于移动端“我的”二级入口，底部保持“我的”高亮。
- 阅读文章时隐藏门户页头与全局底栏，仅显示文章上下文操作栏。
- “我的”不进入站点地图，并使用 `noindex,nofollow`。
- 未登录显示登录/注册引导；会话、订单、权限与防复制边界仍由既有服务端实现负责。

## 风险与回滚

- 移动适配全部位于前端布局、样式和客户端交互；服务端和数据模型不变。
- 回滚只需恢复本功能提交并重新构建静态前端，不需要数据库回滚。
- 浏览器端防复制只能增加复制成本，不能防止截图、OCR 或开发者工具；服务端授权仍是安全边界。
